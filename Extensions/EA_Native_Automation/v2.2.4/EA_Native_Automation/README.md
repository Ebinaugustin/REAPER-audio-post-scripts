# EA Native Automation 2.2.4

Windows x64 REAPER native extension with a headless Lua engine.

Restart REAPER after installing or updating. In the Main Actions list, run:
EA: Native Automation (JUCE) - toggle panel

Search EA: Automation to assign shortcuts to the 88 individual actions.
Right-click the panel for themes, size, docking, version and Run at startup.

Known issues: track volume/pan Manual Write has reported cursor dips or two-point writes, and unexpected envelope lane visibility. Live host confirmation remains pending after recent hotfixes. See VALIDATION.md for the limits of automated checks.
